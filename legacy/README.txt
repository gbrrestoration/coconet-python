CoCoNet v3 provided to T. Iwanaga by S. Condie.

Files are for version 3 of CoCoNet.

CoCoNet is developed in NetLogo

Files are:
- coastline.csv : Coordinates indicating Queensland coastline
- CoCoNet V3_rubble.nlogo : File defining the model + everything else
- CoCoNet V3_rubble_bkup.nlogo : Copy made by T. Iwanaga of the above
- CoCoNet V3_rubble_opt.nlogo : Copy of main model file with added timers and other changes to profile model runtime performance, start investigating potential changes to improve runtimes.

Other CSV files are all data needed to run CoCoNet.
